# coop-order-sorter
Help to sort our frontier order.

Open the app: https://real-raven575.github.io/coop-order-sorter/

- Load the order CSV (member,line,item,upc,name,qty,status), then one box slip CSV at a time (case,line,item,name,qty).
- Scan with a USB scanner, the live camera, or a photo. The app shows whose pile each item goes in.
- All order data stays in your own browser (localStorage). Nothing is uploaded, and this repo holds no order data.
